## 🌟 核心功能特性

### 1. 🎮 本机单机游戏全平台自动识别与修改器推荐（New in v1.1.0）
- **多平台全自动探测**：自动识别 Steam 多盘符库（多驱动器 `libraryfolders.vdf` 及 `appmanifest`）、Epic Games、GOG Galaxy、Ubisoft Connect 等主流平台。
- **自定义游戏目录识别**：自动扫描常见单机游戏目录（如 `D:\Games`、`E:\单机游戏`）。
- **真实游戏可执行文件严格校验**：深度校验目录是否包含真实游戏主程序（`.exe`），智能过滤 0 字节残留空文件夹、卸载器、崩溃收集器等杂质，绝不误报非游戏软件。
- **首页「🎮 本机游戏」专属 Tab**：默认启动即展示本机已安装游戏及对应修改器，专属「💻 本机已安装」徽章及安装路径提示。
- **「🔄 重新扫描」随心刷新**：随时一键全盘深度重扫新安装的单机游戏。

### 2. ⚡ 未收录新游戏“双阶段”智能探针与云端自动补齐（New in v1.1.0）
- **Phase 1（离线毫秒对齐）**：启动即刻与离线 750+ 数据库毫秒级匹配。
- **Phase 2（后台异步联网探针）**：对离线库中尚未收录的最新发售大作，后台自动向风灵官网发起智能中英文探针检索，实时拉取并补齐最新修改器。
- **本地持久化增量缓存**：联网探测到的新修改器自动沉淀至本地 `cache/user_trainers.json`，离线断网亦可长久使用。

### 3. 📚 单机大作全量收录，纯净零网络干扰
- 涵盖《黑神话：悟空》《艾尔登法环》《赛博朋克2077》《对马岛之魂》《巫师3》《荒野大镖客2》等全量单机 3A 大作与热门独立神作。
- 严格过滤剔除一切网络联机游戏与虚假死链，每一款都是真实可用的纯单机修改器。

### 4. 🔍 双引擎极速搜索（离线秒查 + 联网智能补齐）
- **离线毫秒级响应**：没网断网也能秒搜！支持游戏中文原名、常用别名、英文原名、拼音缩写及标点容错。
- **官网动态联网补齐**：遇到最新推出的修改器，后台自动联动官网实时索引补齐，永不过时。
- **丝滑输入体验**：深度防抖与内存缓存优化，输入删减 60 帧顺滑，支持回车即搜与一键清空。

### 5. ⚡ 一键极速下载 & 智能自愈解压
- 直连官方源，满速不限速直接拉取。
- 下载后全自动静默解压，智能识别主程序与反作弊绕过补丁，彻底告别繁琐的手动解压操作。

### 6. 🔲 海报大卡片 / 极简纯文字双视图
- **精美海报模式**：高清封面卡片，热门标识、就绪状态与本机已安装徽章一目了然。
- **紧凑列表模式**：极简纯游戏名模式，单屏展示更多游戏，低调清爽。

### 7. 🛡️ 内置“Defender 防误删一键加白”
- 彻底解决修改器被 Windows 安全中心误报、拦截、静默隔离的最大痛点，一键配置排除项，小白也能轻松搞定。

### 8. 🌿 绿色便携，零残留
- 解压即用，不写系统注册表，自带独立管理与一键删除功能，用完即删不留垃圾。

## 📝 版本更新日志

### [v1.1.0] - 2026-09-25

#### 🚀 新增功能
* **本机单机游戏全平台自动识别**：
  * 支持多盘符 Steam 游戏库自动探测与 `appmanifest_*.acf` 状态解析。
  * 支持 Epic Games、GOG Galaxy、Ubisoft Connect 及常见游戏目录（`Games`、`单机游戏` 等）。
  * 默认首页启动新增「🎮 本机游戏 (数量)」分类与「🔄 重新扫描本机」功能。
  * 卡片与列表项新增「💻 本机已安装」专属徽章与路径悬停提示。
* **新游戏双阶段智能探针与云端自动补齐**：
  * 针对离线库未收录的新发布游戏，后台自动并发向官网发起智能检索。
  * 探测命中后自动拉取海报与下载源追加展示，并持久化缓存至 `cache/user_trainers.json`。
* **未匹配游戏归纳展示**：
  * 界面底部新增「🔍 本机检测到的其他游戏 (暂未匹配到修改器)」可折叠查看面板。

#### 🛠️ 体验优化与问题修复
* **彻底移除冗余的“热键详情”与右侧抽屉**：
  * 界面全面精简，去除全部热键详情按钮与侧边抽屉，专注纯粹修改器下载与运行。
  * 去除二进制 PE 解析开销，启动与加载速度成倍提升。
  * 优化按钮布局：未下载时展示通栏深蓝【下载修改器】，已下载时并排展示绿色【打开修改器】与暗红【删除】。
* **增加单机游戏可执行文件严格校验（`IsValidGameDirectory`）**：
  * 严格校验游戏目录非空（0 字节/0 文件的空文件夹直接剔除，彻底杜绝已卸载残留空目录误判）。
  * 深度检验游戏主程序（`.exe` 且大小 >= 2MB），智能排除卸载程序（`unins000.exe`）、崩溃收集器（`crashpad.exe`）、DirectX 安装包等工具。
  * 校验 Steam 官方清单安装状态（`StateFlags == 4`）。
* **彻底废除 Windows 通用软件注册表盲目扫描**：
  * 彻底杜绝把 360安全卫士、百度网盘、豆包输入法、坚果云等普通办公软件误当成游戏展示的严重漏洞。
* **修复部分游戏封面匹配偏差与搜索卡顿**：
  * 引入 220ms 搜索防抖与异步取消机制，输入检索丝滑顺畅。
